# HanmaGram Desktop

Кастомный клиент Telegram Desktop на базе AyuGram с поддержкой системы плагинов и расширенными возможностями.

**Автор:** [@hanmadef](https://t.me/hanmadef)

## Основные возможности

- **Система плагинов:** поддержка и совместимость мобильных плагинов (.plugin), менеджер установки, включения и отключения плагинов
- **Режим призрака (Ghost Mode):** не читать сообщения, не читать истории, скрыть статус онлайн, не отправлять статус набора текста
- **История сообщений:** сохранение удаленных и отредактированных сообщений
- **Кастомизация внешнего вида:** скругления аватарок, шрифты, стили блоков сообщений, иконки
- **Режим стримера:** скрытие конфиденциальных данных и диалогов при записи экрана или трансляции
- **Локальный Telegram Premium:** доступ к премиум-функциям на клиенте
- **Встроенный переводчик:** перевод сообщений через несколько провайдеров
- **Расширенные фильтры сообщений**
